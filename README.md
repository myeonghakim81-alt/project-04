# 탱크 아케이드 - 프로토타입 (v0.1)

`tank_arcade_gdd.md` 기획서의 "11. 프로토타입 범위 제안 (v0.1 MVP)"를 기반으로 만든 플레이 가능한 웹 프로토타입입니다.
순수 HTML5 Canvas + Vanilla JS로 제작되어 별도 빌드 과정 없이 바로 실행할 수 있습니다.

## 실행 방법

정적 파일이므로 아무 로컬 서버로 열면 됩니다. 예)

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

(`index.html`을 파일로 직접 더블클릭해서 열어도 대부분의 브라우저에서 동작합니다.)

## 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 8방향 이동 (탱크 몸체가 이동 방향으로 회전) |
| Space | 현재 선택된 무기로 발사 (누르고 있으면 쿨다운마다 연사) |
| Shift | 일반 미사일 ↔ 특수(파괴) 미사일 전환 |

## 구현된 MVP 범위

기획서 11번 항목 기준 구현 내역:

1. **필드/미로**: 배틀시티 스타일 파괴 가능한 벽 필드. 스테이지(시드)마다 절차적으로 생성.
2. **플레이어 탱크**: 이동, 일반 미사일(벽에 막힘), 특수 미사일(벽+적 파괴, 탄약 제한, 소진 시 자동으로 일반 전환).
3. **적 (기본형 1종)**: 평상시 순찰(랜덤 이동), 플레이어 접근 시 추적 + 조준 발사.
4. **파괴/피격 로직**: 특수 미사일로 벽 파괴, 미사일 피격 시 적 즉사(1hp), 플레이어 3회 피격 시 게임오버(피격 후 짧은 무적시간 존재).
5. **아이템 2종**: 특수 미사일 탄약팩, 에너지 회복팩. 벽 파괴/적 처치 시 확률적으로 드랍.
6. **스테이지 클리어 루프**: 스폰된 모든 적 처치 시 클리어, 스테이지별 제한시간 타이머(초과 시 게임오버).
7. **스코어**: 벽 파괴 +10 / 적 처치 +100 / 아이템 획득 +20 + 스테이지 클리어 시 남은 시간 보너스.

MVP 이후 확장으로, 스테이지를 클리어하면 다음 스테이지로 진행하며 적 수가 기획서의 난이도 곡선(1→2→4→8→…)을 따라 증가하고, 필드에 동시에 존재하는 적 수는 최대치로 제한되어 순차 스폰(웨이브 방식)됩니다. 중간보스·리더보드·절차적 맵 다양화 등은 기획서에 명시된 대로 이후 단계 과제로 남겨두었습니다.

## 프로토타입 단계에서 내린 결정 (기획서 10번 Open Questions)

- **플랫폼/스택**: 웹 브라우저, HTML5 Canvas + Vanilla JS (빌드 불필요, 가장 빠른 프로토타이핑)
- **그래픽 스타일**: 심플 벡터(도형 기반) 탑다운
- **이동 방식**: 8방향 + 탱크 회전
- **목숨/컨티뉴**: 없음 (에너지 3 소진 시 즉시 게임오버, 재시작만 지원)
- **엔드리스 vs 고정 스테이지**: 엔드리스 (스테이지가 오를수록 적 수 증가, 제한시간 소폭 감소)

## 파일 구조

```
index.html          HTML 뼈대 + 시작/클리어/게임오버 오버레이
style.css           레이아웃 및 오버레이 스타일
js/constants.js      게임 밸런스/치수 상수
js/maze.js           시드 기반 미로 생성, 렌더링, 충돌 판정
js/entities.js        Player / Enemy / Bullet / Item 클래스
js/game.js            게임 루프, 상태 머신, 입력, HUD, 스폰/충돌 처리
```
